# Invoice Keeper — Telegram bot

## Функции
- Главное меню: `/start`
- Список счетов на ближайшие 7 дней: `/payments`
- Просроченные счета: `/overdue`
- Сводка: `/summary`
- Карточки счетов, постраничная навигация и напоминания.

Локальная SQLite-база не используется. Данные запрашиваются из HTTP API.

## Запуск
1. Установите зависимости: `python -m pip install -r requirements.txt`
2. Создайте `.env` рядом с `bot.py`:
   `BOT_TOKEN=...`
   `CHAT_ID=...`
   `API_BASE_URL=https://адрес-источника`
   `API_TOKEN=...` (если требуется)
3. Запустите: `python bot.py`

`CHAT_ID` ограничивает финансовые команды и уведомления одним чатом. Без него бот запускается, но финансовые разделы недоступны.

## Проверки
`python -m unittest -v test_bot_features`

Тесты используют фиктивные данные только внутри тестов и не отправляют сообщения в Telegram.
