# Визуальное направление Invoice Keeper

Утверждённая основа: светлая рабочая панель по мотивам Aéza, верхняя навигация, крупная чёрная типографика, чёрные кнопки. Компактный знак é с чёрным чеком справа снизу плавно раскрывает Invoice Keeper при наведении и клавиатурном фокусе.

## Приоритет информации
1. Период и срок оплаты: календарная дата остаётся датой по МСК, без преобразования в UTC.
2. Текущий статус: «Не оплачено» нейтральный; «Просрочено» красный; «Оплачено» зелёный; «Оплачено с опозданием» янтарный. Статусы всегда подписаны текстом.
3. Основное действие: добавить правило или отметить оплату конкретного периода. Коррекция даты и отмена доступны из деталей периода.
4. Сводка обязательств по срокам: три отдельные карточки RUB/USD/EUR. Всего, оплачено, не оплачено; «из них просрочено» вложено в неоплаченное. Данные и суммы приходят из API, не из загруженной страницы.

## Токены
- Фон #f4f6f7, поверхность #ffffff, приглушённая поверхность #f0f3f4.
- Основной текст и кнопки #141616, вторичный текст #5f6873, границы #e2e7e9.
- Бирюзовый #16a7bb: только небольшие графические акценты; чек логотипа чёрный.
- Оплачено: #216b41 на #e8f5ec; просрочено: #a52936 на #fdecef; поздняя оплата: #31543f на #f4f7f4, оговорка о сроке #80521a.
- Шрифт системный современный гротеск, заголовок 40–56px, основной текст 14–16px; деньги выровнены, с табличными цифрами.
- Радиусы 24px для панелей, 12px для кнопок/полей, мягкие редкие тени.

## Рабочая компоновка
Верхнее меню → заголовок и действие администратора → серверная сводка → фильтры → список периодов → пагинация. История по умолчанию включает прекращённые правила. Формы открываются в доступной боковой панели с управлением фокусом и клавишей Escape. На телефоне данные превращаются в карточки, навигация переносится без горизонтального переполнения; сумма, дата и действие остаются видимыми.

## Доступность и состояния
Кнопки от 44px по высоте на сенсорном экране; видимый фокус; подписи полей, ошибки через aria-describedby; статус не определяется только цветом. Анимация отключается при prefers-reduced-motion. Загрузка, пустой ответ, 401/403, ошибки валидации и недоступность полноты периодов отображаются явно. 503 PERIODS_NOT_READY не подменяется нулями.

## Границы реализации
Это локальный React/Vite frontend для команды, с заменяемым демо-транспортом и интеграцией с будущим API по прилагаемому контракту. Бэкенд, миграции, Telegram worker и публикация сайта не входят в эту задачу.

Название логотипа раскрывается по словам; на планшете меню переносится отдельной строкой. Подробности в visual-refresh.md.
