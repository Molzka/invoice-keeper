# Цветные иллюстрации и отклик интерфейса

## Визуальное направление

Сохранены чёрные основные кнопки, светлый фон и белые карточки. Декор получил мягкие цветные акценты: бирюзовый в платежах, сиреневый в повторениях, тёплый янтарный в истории и мятный в пользователях.

В заголовках — бумажные SVG-композиции с градиентами, подложками, цветными значками и тонким пунктирным маршрутом. В карточках RUB/USD/EUR — многослойные таблички со знаками валют, небольшие орбиты и детали. Код валюты и верхняя кромка поддерживают соответствующий оттенок. Финансовый текст остаётся контрастным; цвета статусов и суммы не менялись.

Короткая прорисовка/появление выполняется один раз. На наведении композиции слегка приподнимаются. Чёрные кнопки получают мягкий блик, вторичные — бирюзовый отклик. Иконки отвечают на действие: плюс поворачивается, обновление разворачивается на 65°, история слегка наклоняется, стрелки смещаются в направлении перехода. Опасные действия сохраняют красный отклик без игровых поворотов. В навигации добавлен небольшой бирюзовый индикатор.

Декор занимает свободную колонку заголовка, не получает фокус и не перехватывает клики. На телефоне иллюстрации компактно кадрируются. Пространственное наведение работает только с точным указателем; учтены клавиатурный фокус, disabled и reduced motion. Бесконечных декоративных анимаций нет. Логин не менялся.

## Проверки

- `npm run build`: TypeScript и Vite успешно.
- `npm run lint`: 0 предупреждений.
- `npm test`: 6 тестов успешно, включая API-диагностику и общую демо-дату.
- Для актуальных package/lock ранее успешно выполнен `npm ci`; новые зависимости в этом оформлении не добавлялись.
- В браузере: все четыре раздела на 320, 900 и настольной ширине; валютные карточки на 390 px. Переполнения и пересечения текста с колонкой иллюстрации нет.
- Подтверждены бирюзовый hover и поворот иконки обновления, видимый фокус кнопки при клавиатурном вводе. Декоративные SVG имеют `aria-hidden` и `pointer-events: none`.

Диагностика отсутствующего платёжного API сохранена: 404 коллекций объясняет проблему подключения, 404 конкретной записи и 503 `PERIODS_NOT_READY` сохраняют отдельную семантику. Ошибки не подменяются тестовыми данными или нулями. Подробности — в [integration.md](integration.md).

Полный Docker/backend и существующие e2e с реальной БД локально не запускались. В проверенном main платёжные маршруты пока отсутствовали.
