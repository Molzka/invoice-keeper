# Контурный фон и диагностика интеграции

## Визуальное направление

Чёрные основные действия, белые карточки и нейтральный серый фон сохранены. В карточках RUB/USD/EUR добавлены крупные полупрозрачные контурные знаки валют, отделённые от финансового текста по слоям. Итоги и статусы не менялись.

В заголовках четырёх рабочих разделов — тонкие пунктирные маршруты со стрелкой и разные SVG-объекты: квитанция, повторение, журнал, карточки доступа. Декор занимает отдельную свободную колонку, не перехватывает клики, скрыт от скринридера. На телефоне остаётся небольшой правый объект.

Добавлены однократная прорисовка маршрута и появление контуров, мягкая реакция знаков валют на наведение. Продолжают работать существующие анимации кнопок, списков и панелей. Бесконечного фонового движения нет; `prefers-reduced-motion` отключает движение. Разметка и оформление логина не менялись.

## Проверки

- `npm ci` с актуальными package/lock из main: успешно; новые зависимости не добавлялись.
- `npm run build`: TypeScript и Vite успешно.
- `npm run lint`: 0 предупреждений.
- `npm test`: 6 тестов успешно, включая 5 новых проверок API-ошибок и прежний тест общей демо-даты.
- В браузере: все четыре раздела на 320, 900 и настольной ширине; карточки на 390 px. Горизонтального переполнения и пересечения декора с текстом нет.
- В изолированном real-режиме с HTTP-fixture: auth/me успешен, платёжные коллекции возвращают контрактный 404. Отображается понятная диагностика, раскрытие технических деталей доступно с Enter. Карточек с ложными нулевыми итогами нет.
- Автотесты API проверяют JSON/HTML 404, обычный 404 конкретной записи, 503 PERIODS_NOT_READY, отсутствие query в диагностике, cookie/CSRF/401 и единственную попытку POST при сетевой ошибке/тайм-ауте.

Полный Docker/backend стек и существующие e2e авторизации/пользователей локально не запускались. В main отсутствует платёжный API; fixture проверяет обработку ошибки, а не готовность реальных платежей. Подробности и настройки режима — в [integration.md](integration.md).
