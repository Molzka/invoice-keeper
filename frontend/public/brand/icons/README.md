# Original Aeza icons

Vector paths extracted directly from page 21 (Иконки) of the user-supplied Aeza Guidebook 2026. These are the original silhouettes, not Phosphor approximations or traced raster images.

- `*-dark.svg`: original guide geometry with a matte graphite tile (#1B2027) and cyan glyph, adjusted locally after visual feedback so it remains visible on black.
- `*-light.svg`: the same guide geometry with a white tile and black glyph. Tile color adaptations are interface treatments, not separately supplied guidebook assets.
- `*-glyph.svg`: original foreground paths with `currentColor`, no tile, centered in a square viewBox for small interface controls.

Names: shield, chart, credit-card, note-pencil, flag, headset, users, chat, bag, hourglass.
