# Настройки приложения

## Права и пароли

Администратор создаётся командой `python -m app.cli create-admin` из `ADMIN_USERNAME` и `ADMIN_PASSWORD`. Через панель нельзя изменить или удалить его учётную запись. Запрос смены собственного пароля с верными данными отклоняется с `403 ADMIN_ACCOUNT_PROTECTED`; пароль и действующие сессии сохраняются. Повторный запуск `create-admin` и изменение `.env` не сбрасывают пароль существующего администратора.

Обычный пользователь может менять свой пароль. При успехе текущая сессия заменяется, остальные отзываются. Клиент получает новый CSRF-токен. Если действие недоступно, проверьте роль в `/api/v1/auth/me`. Подробности — в [контракте смены пароля](../backend/docs/frontend-password-change.md).

## Часовой пояс

`APP_TIMEZONE` принимает имя IANA, например `Europe/Moscow` или `Asia/Tokyo`. По умолчанию используется Москва. Неизвестное имя вызывает ошибку при запуске backend.

API использует настройку для определения сегодняшнего дня и возвращает её в поле `timezone` ответов login/me/change-password. Браузер и бот используют это значение вместо пояса устройства. Worker получает тот же `APP_TIMEZONE` из Compose.

`due_date` и `paid_on` — календарные даты. Они не переводятся в UTC. Напоминание назначается на 00:00 за три календарных дня до срока в поясе приложения; техническое время очереди хранится в UTC. При сезонном переводе часов три календарных дня могут отличаться от 72 часов.

Браузер обновляет текущую дату каждые 30 секунд и при возвращении фокуса. После полуночи обновляются списки и сводка. Дата, выбранная в открытой форме оплаты, сохраняется; меняются подсказка и допустимая верхняя граница.

### Изменение настройки

Остановите backend и worker, измените общий `APP_TIMEZONE`, пересоздайте backend, worker и bot, затем обновите страницы. При раздельном запуске значения API и worker должны совпадать. Команды приведены в [памятке доставки](../backend/docs/reminder-integration.md#смена-часового-пояса-существующего-стенда).

Worker пересчитывает расписание ожидающих `pending` и `retry`, сохраняя отдельные отсрочки и паузы повторных попыток. Подтверждённые отправки не повторяются, даты платежей и оплат не изменяются. Смена пояса не разрешает состояние `unknown`: сначала нужно проверить, дошло ли сообщение в чат.

Если дата выглядит неверно, сравните `APP_TIMEZONE` API/worker с `timezone` в `/api/v1/auth/me`, пересоздайте процессы и обновите страницу.

## Обновление OpenAPI

Swagger доступен по `/api/v1/docs`, файл спецификации — [backend/openapi.json](../backend/openapi.json). После изменения маршрутов или моделей выполните из корня:

```sh
cd backend
uv run --locked python scripts/export_openapi.py
uv run --locked python scripts/export_openapi.py --check
```

Экспорт не требует запущенной БД. `--check` не меняет файл и завершается ошибкой, если он отсутствует или устарел. В этом случае повторите экспорт и просмотрите diff вместе с изменением API.
