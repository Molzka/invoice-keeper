# Все просрочки и компактный рабочий экран

Главный экран сохраняет месячную сводку RUB/USD/EUR. Отдельная строка над ней
показывает количество сохранённых неоплаченных просроченных периодов за всё
время и самый ранний срок. Используется существующий список периодов с
`status=unpaid`, `is_overdue=true`, `limit=1`; валютные суммы не складываются.
Ошибка загрузки не заменяется нулём — доступна повторная попытка.

«Все просрочки» открывает историю без границ дат, валюты и отдельного правила.
Оплаченные и отменённые периоды не включаются. Фильтры и пагинация остаются
в URL, поэтому результат сохраняется после обновления страницы. Обычная
кнопка «Просрочено» в месячном списке продолжает учитывать его диапазон дат.

До 1000 px раздел выбирается через существующий доступный `SelectField`.
Пункты администратора видны только его роли. До 760 px валюты представлены
раскрывающимися строками, а фильтры открываются кнопкой «Период и валюта»;
применённый диапазон и валюта видны и в закрытом состоянии. На узком экране
длинная сумма получает отдельную строку. Скрытый при смене ширины элемент
закрывает свой календарь или список выбора.

Проверка `workspace-overdue.spec.ts` использует управляемые ответы API только
для браузерного сценария: долг прошлого месяца, оплаченный/отменённый период,
ошибка и повторная загрузка, фильтры, клавиатура, роли, пустой список,
светлая/тёмная темы и ширины 320/390/768/1440 px. Реальные права API и правила
платежей по-прежнему проверяются отдельными интеграционными сценариями.
