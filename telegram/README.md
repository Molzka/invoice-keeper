# Telegram-модуль Invoice Keeper

Этот каталог содержит бота aiogram, cookie-клиент API, форматирование сообщений, `Dockerfile`, `.dockerignore` и зафиксированные Python-зависимости. Общий Compose находится [в корне проекта](../compose.yaml).

Из корня репозитория (перед запуском бота задайте `API_BASE_URL` и `API_ORIGIN` по [инструкции локального запуска](../docs/operations/telegram.md#локальный-запуск-из-каталога-проекта)):

```sh
uv sync --locked --directory telegram
uv run --locked --project telegram python -X utf8 telegram/smoke.py --dry-run
uv run --locked --project telegram python -X utf8 telegram/bot.py
```

`--locked` проверяет зафиксированные зависимости, а `-X utf8` включает корректный вывод кириллицы и символов Telegram в Windows. Локальные процессы читают корневой `.env`. Копировать его в `telegram/.env` не нужно; переменные окружения процесса имеют приоритет. Smoke по умолчанию печатает примеры, реальная отправка требует явного `--send`.

В Docker рабочий каталог остаётся `/app`, поэтому команда проверки прежняя:

```sh
docker compose run --rm --no-deps bot python smoke.py --dry-run
```

`/menu` и `/start` открывают меню. В рабочем чате сотрудник выбирает список, открывает карточку по названию и возвращается на прежнюю страницу кнопкой «К списку». Списки показывают по пять записей, полные названия и общее количество; длинные подписи кнопок сокращаются. «Обновить» перечитывает данные, после ошибки доступно «Повторить». Навигация кнопками обновляет текущее сообщение. Вне рабочего чата финансовых кнопок нет, доступны помощь и настройка.

Бот читает финансовые данные API под отдельным обычным пользователем. Оплату и её дату меняют только в веб-панели под личной учётной записью сотрудника. Общий API-пользователь бота не связан с каждым Telegram-участником, поэтому кнопок изменения оплаты нет. Напоминания обязательны по исходному ТЗ, стр. 7–8; кнопка «Оплачено» — дополнительная возможность на стр. 16. [Границы реализации и сценарий сотрудника](../docs/operations/telegram.md#почему-оплата-остаётся-в-веб-панели).

Автоматические напоминания отправляет backend worker через постоянную очередь, отдельного планировщика в боте нет. «Открыть платёж» в напоминании открывает актуальную карточку по UUID новым сообщением и сохраняет исходное уведомление. Эта кнопка ничего не оплачивает. Настройка `PANEL_URL` добавляет прямую ссылку «Открыть веб-панель».
